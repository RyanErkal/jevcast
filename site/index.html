Find something you copied.

Type clip to search text, links, files, and even words in screenshots. Press Return to copy a result. History stays on your Mac and skips password managers.

What stays on your Mac?

App and file search, window shortcuts, and clipboard history work locally. Jevcast needs no account and collects no analytics.

The app checks GitHub for updates. Mail can load remote images. You choose which accounts to connect and whether to send requests to AI providers.

Install

Terminal 
brew install zig@0.15
xcodebuild -downloadComponent MetalToolchain
git clone https://github.com/RyanErkal/jevcast.git
cd jevcast
scripts/build.sh

Needs Xcode 26 or later with its Metal Toolchain, and Zig 0.15 for the terminal. Runs on macOS 14 or later. Read the README

Install Jevcast from the official source repository: https://github.com/RyanErkal/jevcast. Check that this Mac can run Xcode 26 or later and has it installed; otherwise stop and report the requirement. Clone the repository and check out its latest published release tag; if there is no release tag, stop. Verify that `git remote get-url origin` resolves exactly to `https://github.com/RyanErkal/jevcast.git`. If the checkout has `scripts/ghosttykit.sh`, install Homebrew's `zig@0.15` and Xcode's Metal Toolchain (`xcodebuild -downloadComponent MetalToolchain`), then run `scripts/ghosttykit.sh`. Run `swift test` and `scripts/build.sh`, then verify the app with `codesign --verify --deep --strict --verbose=2 "dist/Jevcast.app"`. After those checks pass, quit any running Jev Launcher or Jevcast. Back up an existing `/Applications/Jevcast.app` before replacing it, keep all preferences and settings, install the new app, and open it. Do not bypass Gatekeeper or change macOS security settings.

Questions

Can I keep using Spotlight or Raycast?

You can use them together. If Option–Space is taken, choose a different shortcut in Jevcast Settings.

How do updates work?

Jevcast checks GitHub daily. When a release is ready, use the install instructions above to update.
